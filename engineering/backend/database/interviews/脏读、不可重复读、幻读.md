# 脏读、不可重复读、幻读的区别

不完全对，你混淆了**不可重复读**和**幻读**。

| | 脏读 | 不可重复读 | 幻读 |
|---|---|---|---|
| **读到了什么** | 其他事务**未提交**的数据 | 其他事务**已提交**的**修改** | 其他事务**已提交**的**新插入行** |
| **数据状态** | 临时数据，可能回滚 | 旧数据被覆盖了 | 第一次查没有，第二次查有了 |
| **操作类型** | UPDATE | UPDATE / DELETE | INSERT |

---

### 具体例子

假设表里有 `id=1, name='Alice'` 这一条数据。

**脏读（读到未提交）：**
```
事务A：UPDATE user SET name='Bob' WHERE id=1;   -- 未提交
事务B：SELECT name FROM user WHERE id=1;         -- 读到 'Bob'
事务A：ROLLBACK;                                  -- 回滚了！
```
事务B 读到的 `'Bob'` 是**垃圾数据**，因为事务A 最终回滚了。这就是脏读。

---

**不可重复读（同一行被修改）：**
```
事务A：SELECT name FROM user WHERE id=1;         -- 读到 'Alice'
事务B：UPDATE user SET name='Bob' WHERE id=1;  -- 提交
事务A：SELECT name FROM user WHERE id=1;         -- 读到 'Bob'
```
同一行数据，两次读不一样。重点是**已有数据被修改**。

---

**幻读（读到了新行）：**
```
事务A：SELECT * FROM user WHERE age > 20;        -- 读到 10 条
事务B：INSERT INTO user (age, name) VALUES (25, 'New'); -- 提交
事务A：SELECT * FROM user WHERE age > 20;        -- 读到 11 条
```
**没有哪条旧数据被修改**，但多出来一条**新插入的行**，像幻觉一样。这就是幻读。

---

### 你的理解修正

- **幻读**：不是"更新的记录"，而是**新插入的记录**。已有记录被更新那叫**不可重复读**。
- **脏读**：不是泛泛的"更新过后的数据"，而是特指**其他事务未提交的数据**（可能回滚，读了白读）。

---

### 一句话记忆

> **脏读** = 读了别人还没定稿的草稿  
> **不可重复读** = 同一本书，第二次读发现内容被改过了  
> **幻读** = 书架上突然多了一本你之前没见过的书
