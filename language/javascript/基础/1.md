#### Number的精度问题

```js
0.1 + 0.2 === 0.3;  // false

// 原因：IEEE 754 双精度浮点，0.1 和 0.2 在二进制下是无限循环小数
// 存储时被截断为 52 位尾数，相加后精度丢失

// 解决方案
Math.abs(0.1 + 0.2 - 0.3) < Number.EPSILON;  // true
(0.1 * 10 + 0.2 * 10) / 10 === 0.3;           // true（先转整数运算）

// 安全整数范围
Number.MAX_SAFE_INTEGER;  // 9007199254740991（2^53 - 1）
Number.MIN_SAFE_INTEGER;  // -9007199254740991
```

### 类型转换

#### 显式转换

```js
Number("42");       // 42
Number("");         // 0
Number("hello");    // NaN
Number(null);       // 0
Number(undefined);  // NaN

String(42);         // "42"
String(null);       // "null"

Boolean("");        // false
Boolean(null);      // false
Boolean(undefined); // false
Boolean(NaN);       // false

// 其余全为 true，包括 []、{}、"0"、"false"
```

#### 隐式转换

- `+` 操作符: 任一操作数为字符串 -> 字符串拼接，否则转Number
- `- * / %`：全部砖城Number
- `==`: 类型不同转换后比较
- `> < >= <=`: 转Number比较：若两边都是字符串则按照字典序
- `if() / while() / !`：转Boolean
- `obj + 1`: 对象转为原始值

##### `==`的转换规则

1. `null == undefined`: -> true
2. `number == string`: string转成number
3. `boolean == any`：boolean转number(true -> 1, false -> 0)
4. `object == primitive`：object `ToPrimitive`转原始值

```js
[] == ![];   // true
// 步骤拆解：
// 1. ![] → !Boolean([]) → !true → false
// 2. [] == false（boolean 与 object 比较，boolean 先转 number）
// 3. [] == 0（object 转 primitive：[].toString() → "" → Number("") → 0）
// 4. 0 == 0 → true

[] + {};     // "[object Object]"
// [] → ""（ToPrimitive）
// {} → "[object Object]"（ToPrimitive）
// "" + "[object Object]" → "[object Object]"

{} + [];     // 0
// {} 被解析为代码块（空语句），+[] → Number([]) → Number("") → 0

{} + {};     // "[object Object][object Object]" 或 NaN（取决于解析为对象还是代码块）
```

##### `==` or `===`

- `===`：类型不同直接 false，无转换，性能略好，推荐默认使用
- `==`：允许类型转换，在明确知道转换行为时可用（如 == null 同时判断 null 和 undefined）

#### 闭包

**定义**：函数可以记住并访问它的词法作用域，即使这个函数在当前作用域之外执行

**本质**：函数对象有一个`[[Environment]]`隐藏属性，指向定义时的词法环境。

```js
function makeCounter() {
  let count = 0
  return function() {
    return ++count // inner has outer reference
  }
}

const counter = makeCounter();
console.log(counter()); // 1
console.log(counter()); // 2
```

risk

```js
function leaky() {
  const hugeArray = new Array(10000000).fill('x')
  return function() {
    console.log(hugeArray[0])
  }
}

const fn = leaky() // hugeArray被闭包引用，无法GC

// resolution: fn = null，解引用，让GC回收
``` 

## `this` q

### 四条规则

1. `new`绑定：`new Foo()` this指向新创建的实例对象
2. 显式绑定： `fn.call(obj)`/ `fn.apply(obj)` / `fn.bind(obj)`，指向制定的obj
3. 隐式绑定：`obj.method()`，调用该方法的对象obj
4. 默认绑定：直接调用`fn()`，非严格模式，全局对象；严格模式：undefined

```js
function foo() {
  console.log(this)
}

foo()

foo.call({ a: 1 })
foo.apply({ a: 2 })
const bound = foo.bind({ a: 3 })
```
### 箭头函数this

箭头函数没有自己的`this`，它继承外层词法作用域的`this`

```js
const obj = {
  name: 'obj',
  regular() {
    console.log(this.name);  // 'obj'
  },
  arrow: () => {
    console.log(this.name);  // undefined（继承全局/外层 this）
  }
};
obj.regular();
obj.arrow();

// 箭头函数不能用 call/apply/bind 改变 this
const fn = () => console.log(this);
fn.call({ a: 1 });  // 仍然指向定义时的 this，不是 { a: 1 }
```

箭头函数的其他限制
- 没有 arguments 对象（可用剩余参数 ...args 替代）
- 没有 prototype 属性
- 不能作为构造器使用（不能 new）

## 原型与原型链

### 核心概念

```plain
构造函数（Constructor）        实例对象（Instance）
  │                              │
  ├─ prototype ───────────────┐  │
  │    （原型对象）              │  │
  │         ↑                  │  │
  │    __proto__               │  │
  │  （实例的原型链指针）        │  │
  │                            ↓  │
  └───────────────────────────────┘
```

- 每个函数(构造器)有`prototype`属性，指向原型对象
- 每个对象有`__proto__`属性，标准方法：`Object.getprototypeOf()`，指向构造函数的`prototype`
- 原型链终点：`Object.prototype.__proto__ === null`
