# 缺失的第一个正数（First Missing Positive）

**题号**：41 | **难度**：Hard（数组类最经典的 Hard）

**描述**：  
给你一个未排序的整数数组 `nums`，请你找出其中没有出现过的 **最小的正整数**。

请你实现时间复杂度为 **O(n)** 并且只使用 **常数级别额外空间** 的解决方案。

**示例**：
```
输入: nums = [1,2,0]
输出: 3
```

```
输入: nums = [3,4,-1,1]
输出: 2
```

```
输入: nums = [7,8,9,11,12]
输出: 1
```

**约束**：
- `1 <= nums.length <= 5 * 10^5`
- `-2^31 <= nums[i] <= 2^31 - 1`

**要求**：O(n) 时间，O(1) 额外空间（不算输入数组本身）。
