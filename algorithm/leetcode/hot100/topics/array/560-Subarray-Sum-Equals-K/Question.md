# 和为 K 的子数组（Subarray Sum Equals K）

题号：560 | 难度：Medium
描述：
给定一个整数数组 nums 和一个整数 k，请统计该数组中 和为 k 的连续子数组 的个数。
示例：
plain
输入: nums = [1,1,1], k = 2
输出: 2
解释: [1,1] 与 [1,1] 为两种不同的情况（下标不同）
plain
输入: nums = [1,2,3], k = 3
输出: 2
解释: [1,2] 和 [3]
约束：
1 <= nums.length <= 2 * 10^4
-1000 <= nums[i] <= 1000
-10^7 <= k <= 10^7
要求：O(n) 时间。
