# 最长连续序列（Longest Consecutive Sequence）

**题目编号**：LeetCode 128  
**难度**：Medium（实际接近 Hard 思维）  
**类别**：数组 / 哈希表

**描述**：  
给定一个未排序的整数数组 `nums`，找出 **数字连续的最长序列**（不要求序列元素在原数组中连续）的长度。

请你设计并实现时间复杂度为 **O(n)** 的算法解决此问题。

**示例**：
```
输入: nums = [100,4,200,1,3,2]
输出: 4
解释: 最长连续序列是 [1, 2, 3, 4]，长度为 4。
```

```
输入: nums = [0,3,7,2,5,8,4,6,0,1]
输出: 9
```

**约束**：
- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

---

**要求**：O(n) 时间复杂度，不能用排序（排序是 O(n log n)）。

## 思路

核心观察：只从"序列起点"开始往后数。
1. 所有数字丢进 Set，O(n)
2. 遍历每个数 num，如果 num - 1 不在 Set 里，说明 num 是一个连续序列的起点
3. 从起点开始 num, num+1, num+2... 一直数到 Set 里没有为止，记录长度
4. 取最大长度
5. 为什么只从起点数？
   - 如果 num - 1 在 Set 里，num 肯定不是起点，它会被前面的起点覆盖到。
   - 每个数字最多被访问两次（一次作为内部元素被 num-1 检查跳过，一次作为起点被数），整体仍是 O(n)。
