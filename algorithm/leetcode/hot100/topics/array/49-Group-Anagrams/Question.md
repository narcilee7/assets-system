# 字母异位词分组（Group Anagrams）

**题号**：49 | **难度**：Medium

**描述**：  
给定一个字符串数组 `strs`，将 **字母异位词** 组合在一起。可以按任意顺序返回结果列表。

字母异位词是由重新排列源单词的字母得到的新单词。

**示例**：
```
输入: strs = ["eat","tea","tan","ate","nat","bat"]
输出: [["bat"],["nat","tan"],["ate","eat","tea"]]
```

**约束**：
- `1 <= strs.length <= 10^4`
- `0 <= strs[i].length <= 100`
- `strs[i]` 仅包含小写字母

---

## 核心思路

排序签名法：字母异位词排序后结果相同，直接作为hash key
