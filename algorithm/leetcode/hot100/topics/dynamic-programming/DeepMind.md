# DP思路

## DP 核心就三句话

**1. 状态定义**  
`dp[i]` 或 `dp[i][j]` 到底代表什么？（如：`dp[i]` = 爬到第 `i` 阶的方法数）

**2. 状态转移**  
`dp[i]` 怎么从子问题推导？（如：`dp[i] = dp[i-1] + dp[i-2]`）

**3. 初始化 + 边界**  
`dp[0]`、`dp[1]` 是什么？循环从哪开始？

---

## DP 面试四大类

| 类型 | 代表题 | 状态维度 |
|------|--------|----------|
| **线性 DP** | 爬楼梯、打家劫舍 | 一维 |
| **序列 DP** | LIS、LCS、编辑距离 | 一维/二维 |
| **背包 DP** | 分割等和子集、零钱兑换 | 一维（空间优化后） |
| **区间 DP** | 最长回文子串、戳气球 | 二维 |

**空间优化口诀**：二维 DP 如果当前行只依赖上一行，可以压成一维；一维 DP 如果只依赖前几个固定位置，可以压成 O(1)。
