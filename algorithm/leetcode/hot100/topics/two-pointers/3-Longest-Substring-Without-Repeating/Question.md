# 无重复字符的最长子串（Longest Substring Without Repeating Characters）
题号：3 | 难度：Medium
描述：
给定一个字符串 s，请你找出其中不含有重复字符的 最长子串 的长度。
示例：
plain
输入: s = "abcabcbb"
输出: 3
解释: 因为无重复字符的最长子串是 "abc"，所以其长度为 3。
plain
输入: s = "bbbbb"
输出: 1
解释: 因为无重复字符的最长子串是 "b"，所以其长度为 1。
plain
输入: s = "pwwkew"
输出: 3
解释: 因为无重复字符的最长子串是 "wke"，所以其长度为 3。
注意，"pwke" 是一个子序列，不是子串。
约束：
0 <= s.length <= 5 * 10^4
s 由英文字母、数字、符号和空格组成
要求：O(n) 时间。
