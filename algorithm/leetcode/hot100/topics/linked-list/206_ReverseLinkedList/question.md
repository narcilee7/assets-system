# 反转链表（Reverse Linked List）

**题号**：206 | **难度**：Easy（链表必会第一题）

**描述**：  
给你单链表的头节点 `head`，请你反转链表，并返回反转后的链表。

**示例**：
```
输入: head = [1,2,3,4,5]
输出: [5,4,3,2,1]
```

```
输入: head = [1,2]
输出: [2,1]
```

```
输入: head = []
输出: []
```

**约束**：
- 链表中节点的数目范围是 `[0, 5000]`
- `-5000 <= Node.val <= 5000`

**要求**：迭代 O(n) 时间，O(1) 额外空间；或递归 O(n) 时间，O(n) 栈空间。

**直接写，写不出来就说。**
